# Claim Bullets

Status: active
Content type: EDUCATIONAL (broad topic)

Flat bullet list where each bold label is a complete claim sentence. Maximally scannable — no sections, no hierarchy.

## Template

```
## [Main heading for the entire video — one sentence, informative]

**TL;DR**: [1 sentence synthesis]

- **[Claim sentence]**: supporting detail as fragment, one or two short sentences max
- **[Claim sentence]**: supporting detail with numbers or mechanism

## Hidden Gems
- **[Claim]**: tangent or side detail outside the main argument
```

## Example

```
## Why thermodynamics sets hard limits on computation

**TL;DR**: Energy dissipation in logic gates is a physical law, not an engineering problem, and Landauer's principle sets the minimum cost per erased bit.

- **Earth radiates back exactly as much energy as it receives**: conservation of energy requires balance — otherwise Earth would heat or cool continuously
- **Entropy measures how spread out energy is**: low entropy = concentrated, able to do work; high entropy = dispersed, unavailable
- **Heat flowing cold→hot is statistically improbable, not forbidden**: at 10²⁵ atoms the probability is effectively zero

## Hidden Gems
- **Reversible computing sidesteps Landauer's limit**: if no bits are erased, no heat is required — Maxwell's demon thought experiment shows this is physically conceivable
```

## Rules

- Main heading: ## level, one sentence, informative enough to convey the video's core topic
- TL;DR: mandatory, never remove, one sentence synthesis of the entire content
- Bold label: complete claim sentence, front-loaded, informative enough to read without the detail
- After colon: fragments or short sentences — evidence, numbers, mechanism. Not full paragraphs.
- Flat list only — NO ### headings, NO hierarchy, NO sections in the main bullet list
- 7-10 bullets for normal content, fewer for short transcripts
- Hidden Gems: end with `## Hidden Gems` if the transcript contains valuable tangents, anecdotes, or details outside the main argument. 1-3 bullets, same claim-bullet format. Omit only if nothing qualifies.

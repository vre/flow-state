# Flat Bullets

Status: active
Content type: TIPS

Bold category label + comma-separated items per line. Fast scanning for practical advice, gear reviews, rankings.

## Template

```
## [Main heading for the entire video — one sentence, informative]

**TL;DR**: [1 sentence synthesis]

- **[Category]**: [item], [item], [item]
- **[Category]**: [item], [item]
```

## Example

```
## Best budget home studio gear in 2024

**TL;DR**: Under $300 you can build a setup that outperforms most webcam rigs — mic and lighting matter more than the camera.

- **Budget picks**: Samson Q2U ($70), Audio-Technica ATR2100x ($99)
- **Lighting**: Ring light for video calls, key light for streaming, avoid overhead fluorescents
- **Cable management**: Velcro straps over zip ties, label both ends, route behind desk
```

## Rules

- Main heading: ## level, one sentence, informative
- TL;DR: mandatory, never remove, one sentence synthesis
- Bold category label followed by colon
- Items comma-separated on same line
- Keep items short — fragments, not sentences
- One category per bullet, group related items
- No Hidden Gems — TIPS content is entirely enumerable; nothing meaningful falls outside a category

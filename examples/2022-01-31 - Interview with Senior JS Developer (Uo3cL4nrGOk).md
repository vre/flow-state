## Summary: Interview with a Senior JS Developer

**TL;DR**: Satirical monologue of every JS absurdity — frameworks churn, types stay unknown, the codebase rewrites itself.

- **Language written in 7 days**: messy by design; 100k Stack Overflow points and still a noob
- **Framework treadmill**: React → Preact → Svelte → vanilla → back; codebase rewritten ~9 times in a month
- **State management spiral**: Redux → Redux Toolkit → Flux → Flummox → Recoil → React Context → rewrite
- **TypeScript doesn't fix types**: "we still don't know" — uncertainty is the language, not the tooling
- **Async hell**: Callbacks → Promises → async/await → Promises → callbacks ("at least you know it's bad")
- **Package manager wars**: npm → yarn → pnpm → turbo; peer deps still unsolved
- **The punchline**: npm + TypeScript + Babel + ES5 + SystemJS + webpack + React + Redux — all to avoid jQuery

- **null is technically an object, except when it's not**: "objects can be null so technically they can be non-objects unless they're an object" — the type system in one sentence
